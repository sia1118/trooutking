SUPER MEISTER SERIES

歴代マイスターおよび前大会のエキスパートシリーズでシード権を獲得した選手を対象とした、トラウトキング選手権大会の新たなシリーズ戦です。予選では1対1の総当たりリーグ戦を採用し、参加人数に応じて6名用・8名用の2種類の進行方式で実施します。
2026年10月30日制定 トラウトキング選手権大会事務局

  • 1. 予選（グループステージ）

    試合進行

    参加人数に応じて、各ブロック5～6名、または7～8名に分かれ、1対1の総当たりリーグ戦を行います。
    各ブロックには4釣座を設け、1試合20分間（前半10分・後半10分）とし、前半終了後に対戦相手と釣座を交代します。
    各試合の勝敗に応じて勝ち点を付与し、各ブロックの上位2名が準決勝へ進出します。

    予選の進行方式

    項目6名用8名用
    適用人数48名以下49名以上
    ブロック人数5～6名7～8名
    試合形式1対1総当たり1対1総当たり
    1人あたりの試合数4～5試合6～7試合
    予選ヒート数8ヒート14ヒート
    1試合の時間20分20分
    試合間インターバル5分5分
    各ブロックの釣座4釣座4釣座
    準決勝進出各ブロック上位2名各ブロック上位2名

    ※各試合は前半10分・後半10分とし、途中で釣座を交代します。
    ※5名・7名ブロックでは、基本となる対戦表から欠員選手が関わる試合を除外します。

    予選ブロックの振り分け方法

    予選ブロックの振り分けは、各選手の実績およびランキングに基づいて決定します。
    特定のブロックに上位選手が集中しないよう、ランキング上位から各ブロックへ順番に選手を配置する「スネーク方式」を採用します。

    ＜第1戦（千早川マス釣り場）の振り分け＞

    第1戦では、参加選手を以下の優先順位で振り分けます。

    1. 歴代マイスター（前大会出場選手）：第25回エキスパートシリーズのポイントランキング順に配置します。
    2. 歴代マイスター（前大会不出場選手）：選手名の五十音順に配置します。
    3. 前大会エキスパートシリーズ・シード権獲得選手：第25回エキスパートシリーズのポイントランキング順に配置します。

    ※ポイントランキングが同順位の場合は、五十音順とします。

    ＜第2戦以降の振り分け＞

    第2戦以降は、歴代マイスター・シード権獲得選手の区分に関係なく、前戦終了時点のスーパーマイスターシリーズ累計ポイントランキング順に振り分けます。
    ※累計ポイントが同点の場合は、五十音順とします。
    ※前戦までに出場していない選手は、累計0ポイントとして扱います。

    ＜スネーク方式について＞

    ランキング上位の選手から、Aブロック、Bブロック、Cブロック……の順番に配置します。
    最終ブロックまで配置した後は、逆方向に折り返して配置を続けます。

    【8ブロックの場合】
    A → B → C → D → E → F → G → H → H → G → F → E → D → C → B → A
    以降も同様に折り返しながら配置します。

    第1戦では、選手区分が切り替わる場合も配置順をリセットせず、継続して振り分けます。
    なお、各ブロックの人数は可能な限り均等になるよう調整します。

    勝ち点

    予選では、各試合の結果に応じて以下の勝ち点を付与します。

    試合結果勝ち点
    勝利3点
    引き分け（双方釣果あり）1点
    敗北0点
    スコアレスドロー（0対0）0点

    各ブロック内の勝ち点によって順位を決定し、上位2名が準決勝へ進出します。

    放流について

    予選中に20分間の放流兼休憩時間を2回設けます。
    放流タイミングは、参加人数に応じて以下のとおりとします。

    【6名用】

    • 1回目：予選第3ヒート終了後
    • 2回目：予選第5ヒート終了後

    【8名用】

    • 1回目：予選第5ヒート終了後
    • 2回目：予選第10ヒート終了後

    いずれも放流兼休憩時間は20分間とします。

  • 2. 参加人数別のブロック編成

    準決勝は原則16名で実施します。
    参加人数に応じて予選ブロック数を調整し、予選通過者が16名に満たない場合は敗者復活戦を実施します。

    参加人数予選方式ブロック数予選通過敗者復活枠準決勝
    57～64名8名用816名なし16名
    49～56名8名用714名2名16名
    41～48名6名用816名なし16名
    37～40名6名用714名2名16名
    31～36名6名用612名4名16名

    ※各ブロックの人数は、できる限り均等になるよう調整します。
    ※参加人数が30名以下、または65名以上となった場合は、別途進行方法を定めます。

  • 3. 敗者復活戦

    試合進行

    予選各ブロックの上位2名が準決勝へ進出した時点で、準決勝進出者が16名に満たない場合に敗者復活戦を実施します。
    敗者復活戦の出場対象者は、予選各ブロック3位の選手とします。

    競技形式

    1匹早掛け方式による対戦を行います。
    出場選手全員が一斉に競技を開始し、最初に1匹を釣り上げた選手から順に勝ち抜けとなります。
    参加人数に応じて定められた勝ち上がり人数に達した時点で、敗者復活戦を終了します。
    競技開始は全体アナウンスにより行います。
    規定人数が決定しない場合は、釣座の変更等を行い、勝ち上がり選手が決定するまで競技を継続します。

    勝ち上がり人数

    参加人数敗者復活戦出場者勝ち上がり人数
    57～64名実施なし―
    49～56名7名2名
    41～48名実施なし―
    37～40名7名2名
    31～36名6名4名

    敗者復活戦を勝ち抜いた選手は、予選各ブロックの上位2名とともに準決勝へ進出します。

  • 4. 準決勝

    試合進行

    予選通過者および敗者復活戦通過者の合計16名によって実施します。
    抽選により4名ずつ4グループに分かれ、各グループで合計40分間（10分×4セット）の釣果数対決を行います。
    各グループの上位2名が決勝へ進出します。

    ローテーション

    10分間の競技終了ごとに釣座を交代し、計3回のローテーションを行います。
    各選手が4つの釣座を順番に使用します。
    ローテーションはグループ内で左ずれとします。
    （例：1,2,3,4 → 2,3,4,1 → 3,4,1,2 → 4,1,2,3）

    勝ち上がり

    各グループの合計釣果数によって順位を決定します。

    • グループ1位：1～4位決定戦へ進出
    • グループ2位：5～8位決定戦へ進出
    • グループ3位・4位：準決勝敗退

    同匹数の場合

    合計釣果数が同数となり、順位が確定しない場合は、該当選手による1匹早掛けのサドンデスを実施し、順位を決定します。

  • 5. 決勝

    試合進行

    準決勝各グループの上位2名による順位決定戦を実施します。

    【1～4位決定戦】
    準決勝各グループの1位選手、計4名による対戦を行います。

    【5～8位決定戦】
    準決勝各グループの2位選手、計4名による対戦を行います。

    競技時間

    それぞれ4名による合計40分間（10分×4セット）の釣果数対決を行います。

    ローテーション

    準決勝と同様に、各セット終了後に釣座を交代します。
    計3回のローテーションを行い、4つの釣座をすべて使用します。

    順位決定

    40分間の合計釣果数によって順位を決定します。
    合計釣果数が同数の場合は、サドンデスにより順位を決定します。
    ※1～4位決定戦と5～8位決定戦は、同時進行を予定しています。

  • レギュレーション・注意事項

    試合中に使用禁止タックルを使用した場合は失格となります。審判はタックル違反を発見した場合、直接その場で該当選手に伝えてください。

  • タックル規定

    タックルは1選手につき合計7本まで釣座への持ち込み・使用が可能です。

  • ルアー規定

    「第26回トラウトキング選手権大会」の協賛メーカーが販売するルアーのみ使用可能です。

    • 協賛メーカーが過去に販売した製品も使用可能です。
    • 協賛管理釣り場のオリジナルルアーは使用可能です。
    • 協賛メーカー製品の非協賛メーカーオリジナルカラーは、カラー変更のみの場合に限り使用可能です。
    • 非協賛メーカー製品および非協賛メーカーとのコラボルアーは使用禁止です。
    • 協賛メーカーの製品であっても、プロトルアーは使用禁止です。

    スプーン

    ＜全長サイズ＞

    • 予選：全長サイズの制限なし
    • 敗者復活戦以降：18mm未満のスプーンは使用禁止

    ＜重量＞

    • 重量6g未満のもののみ使用可能です。

    プラグ

    ＜全長サイズ＞

    • 2cm以上10cm未満のもののみ使用可能です。

    その他

    • スティックルアー、トルネードルアー、ワーム素材、ジグ、トレーラー、フライ素材、起毛加工されたもの、生物素材を使用したルアーは禁止です。
    • ルアーの改造は、着色および認められたウエイト調整を除き禁止です。
    • アイの調整はトゥルーチューンのみ可能です。
    • ウエイト調整はチューニングシンカーによるもののみ可能です。
    • 非協賛メーカー製品の協賛メーカーオリジナルカラーは使用禁止です。

  • フック規定

    • シングルバーブレスフックのみ使用可能です。
    • プラグへのフック装着は合計2本までとします。
    • スプーンへのフック装着は1本までとします。
    • プラグ・スプーンともにラインアイへのフック装着は禁止です。
    • アシストフックは禁止です。
    • フックへの装飾および改造は禁止です。

  • スナップ・スプリットリング規定

    • 著しい重量変化を伴う、ウエイト調整目的のスナップ・スプリットリングの装着は禁止です。
    • スナップ・スプリットリングへの装飾および改造は禁止です。

  • その他

    • ルアー本体以外へのシンカーの使用は禁止です。
    • ランディングネットは全長140cm以下のもののみ使用可能です。
    • 集魚剤（フォーミュラー）の使用は禁止です。

  • タックルチェックについて

    • 審判は試合開始前に選手のタックルチェックを行います。使用禁止タックルを確認した場合は、該当選手に直接警告し、速やかに変更を求めてください。
    • 試合開始前の警告に従いタックルを変更した場合は、ペナルティの対象とはなりません。
    • 試合中に使用禁止タックルを使用した場合は失格となります。

  • カウント規定

    カウント対象

    • エラより前にフックが掛かったトラウト類のみをカウント対象とします。
    • コイ、チョウザメ、その他の魚種はカウント対象外です。
    • 終了コール時点でファイト中の魚はカウント対象となります。
    • カウントの可否はすべて審判が判断します。
    • 陸上げした魚はカウント対象外となります。

    カウント手順

    1. ヒットコール：選手は魚が掛かった際に「ヒット」と発声してください。
    2. ネットイン・確認：魚をランディングネットに取り込む際は、審判が目視できるよう、ネットに入った魚を水面から上げてください。審判はネットインを目視で確認したうえで「OK」とコールし、1匹をカウントしてください。目視で確認できなかった場合はカウントしません。
    3. リリース：選手は審判の「OK」コールを確認した後、水中で魚をリリースしてください。

  • 禁止行為

    以下の行為を禁止します。

    • ランディングネット内で魚をバウンドさせる行為や、ラフなネットインなど魚を傷つける恐れのある行為
    • 置き竿（ロッドから手を離した状態で、ルアーが水に触れている状態）
    • 引っ掛け釣り
    • 審判が迷惑行為・危険行為・不適切行為と判断した行為
    • 指定された釣座の正面方向以外へのキャスティング

    選手が禁止行為を行った場合、審判は直ちに警告してください。
    警告後も改善が見られない場合は、オフィシャルスタッフに確認のうえ、釣果からマイナス1匹のペナルティを科します。

  • 注意事項

    • 違反行為について警告を受けたにもかかわらず、繰り返し違反した選手は失格となり、参加資格を失います。
    • 失格となった場合、参加費および釣券代の返金は行いません。
    • 安全確保のため、メガネまたはサングラス、および帽子を必ず着用してください。
    • 大会中の事故による怪我や盗難等のトラブルについて、主催者は責任を負いかねます。
    • 大会中のルール・レギュレーションの変更に関する権限は主催者に帰属します。
    • 悪天候等により大会を中止する場合があります。予選が開始されている場合、参加費の返金は行いません。
    • 会場となる管理釣り場のレギュレーションと大会レギュレーションが異なる場合は、より制限の厳しい規定を優先します。
